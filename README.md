# 🧑‍💼 Job Listing Portal – Group 2 (Month 3 Batch)

A web-based platform designed to connect job seekers and employers.  
This project is part of the Amdox Internship Program.

---

## 🚀 Project Overview

The Job Listing Portal allows:
- Job seekers to search and apply for jobs  
- Employers to post job openings  
- Users to manage profiles and applications  
- Secure authentication for both job seekers and employers
